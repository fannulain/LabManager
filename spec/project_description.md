# Project Description

## Description
**Project Name:** Educational Materials and Laboratory Manager (LabManager) \
**Project Purpose:** An information system designed to organize and optimize the educational process.

## Key Features:
* **Material Structuring:** Organaizes educational materials and tasks in a clear and accessible format.
* **Deadline Tracking:** Tracks and displays the deadlines for lab work and other academic assignments.
* **Material Archive:** Stores and keeps track of educational materials from previous semesters for future use.
